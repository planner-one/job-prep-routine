# 취업 준비 루틴 보드

매일메일 공식 아카이브의 **백엔드 152개 질문만** 고정한 로컬 스냅샷으로 읽고, 5+5 퀴즈와 면접 답변 연습으로 이어가는 로컬 우선 학습 앱입니다. 프런트엔드 아카이브 문항은 포함하지 않습니다.

## 작업 시작 규칙

사용자가 질문하거나 계획을 물을 때는 설명과 확인만 제공합니다. 파일 수정, 문항 생성, 테스트 실행, 에이전트 작업 등 실제 구현은 사용자가 **“구현해”** 또는 **“시작해”**라고 명시적으로 요청한 경우에만 시작합니다.

## 로컬 실행

```sh
python3 -m http.server 8789 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8789/` 또는 `http://localhost:8789/`를 엽니다. 로컬 저장소에 읽기 상태, 퀴즈 시도, 면접 자가평가와 AI 평가를 분리해 저장합니다.

## 선택형 AI 평가

AI가 없어도 답변·키워드·자신감·복기 메모 저장과 원문 비교는 동작합니다. AI 평가를 쓰려면 [Ollama](https://ollama.com/download)를 설치하고 다음을 준비합니다.

```sh
ollama serve
ollama pull qwen3:14b
```

평가는 `qwen3:14b`, 온도 0, 구조화 JSON을 사용합니다. 원문과 정확히 일치하는 인용을 확인할 수 없는 항목은 검증된 사실 영역에 표시하지 않습니다.

## 데이터·검증

- 원문: `maeil-mail/maeil-mail-contents` 커밋 `d00877afb0a302072078d34ded66b3b69143a5ca`
- 원문 검증: `npm run validate:maeil-content`
- 퀴즈 검증: `npm run validate:quiz-data`
- 전체 테스트: `npm test`
- 문법 검사: `npm run check`

퀴즈는 실행 중 생성하지 않고, Codex가 원문 근거와 함께 작성한 정적 문항 은행을 사용합니다. 정적 은행은 정확한 원문 인용·출처 구역·4개 고유 선택지·단일 정답·중복·메인/꼬리 질문 연결을 검사합니다. Ollama는 선택적인 면접 AI 평가에만 사용하며 퀴즈 생성에는 사용하지 않습니다.

## 현재 구현 상태

- 백엔드 원문 152개 글마다 메인 퀴즈와 꼬리 질문을 하나씩 제공한다. (총 304문항)
- 5+5 객관식 뒤에는 틀린 메인 문항을 우선하는 심화 꼬리 질문을 제공한다.
- 읽기 완료, 메인 퀴즈, 꼬리 질문, 면접 자가평가 완료, AI 평가 완료를 별도 append-only 학습 기록에 누적한다.
- 별도 학습 기록 페이지에서 최근 90일 잔디, 학습 유형별 이력, 퀴즈 정답률을 확인하고 각 퀴즈 기록에서 오답을 펼쳐볼 수 있다.

## 공개 전 확인

공식 콘텐츠 저장소에 별도 라이선스가 표시되어 있지 않으므로, 공개 서비스 전환 전에 재사용 허가·표시 조건을 반드시 확인해야 합니다. 본 프로젝트는 매일메일 브랜드·로고를 복제하지 않는 독립적인 취업 루틴 보드입니다.
