# 매일메일 백엔드 콘텐츠 스냅샷

이 디렉터리는 [`maeil-mail/maeil-mail-contents`](https://github.com/maeil-mail/maeil-mail-contents)의 백엔드 콘텐츠 152개를 커밋 `d00877afb0a302072078d34ded66b3b69143a5ca`에 고정한 로컬 스냅샷입니다. 읽기·퀴즈·면접 연습이 모두 같은 원문을 참조하도록 사용합니다.

- 범위: `backend/contents/be-1.md` ~ `be-152.md` 중 공식 목차에 있는 152개
- 동기화: `npm run sync:maeil-content`
- 무결성: `manifest.json`의 파일별 SHA-256로 검사

원본 저장소에 별도 라이선스 표시가 확인되지 않았습니다. 외부에 공개하기 전에 콘텐츠 재사용 허가와 표시 조건을 반드시 확인해야 합니다.
