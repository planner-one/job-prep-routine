# 일반 면접 준비 대시보드

최신 `v5_3` 이력서와 프로젝트 근거를 기준으로 공통·인성, 이력서 기반 기술질문, 필수 CS를 함께 읽는 개인용 대시보드입니다.

## 배포

루틴 보드의 `/interview/` 경로에 통합되어 GitHub Pages로 함께 배포됩니다.

## 로컬 실행

```bash
cd job-prep-routine
python3 -m http.server 8787 --bind 127.0.0.1
```

- 주소: `http://127.0.0.1:8787/interview/`
- 로컬 컴퓨터에서만 접속할 수 있습니다.
- 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

## 화면 구성

- 질문별 핵심 답변 1문장, 근거 1·2 각 1문장, 핵심 키워드
- 면접 준비 가이드와 대응되는 14문항의 `기존 답변 / 가이드 반영` 비교
- 가이드 표현을 코드·이력서 근거와 대조한 보완 이유와 주의사항
- 짧은 답변은 원문을 자동으로 자르지 않고 문항별로 다듬은 `compact` 문장을 사용
- 중급 핵심문장은 핵심 키워드로 문제·검증·협업 방식을 먼저 전달
- 역할·결론 → 문제·접근 → 검증·결과 → 기술 키워드 순서의 1분 요약
- 질문마다 기초·중급·심화 단계로 나눈 꼬리질문 3개
- 강조점별 120분 루틴 4종
- 난이도별 120분 루틴 4종
- 면접 직전 2시간 압축 복습
- 전체 질문 검색·분류
- 근거가 부족하거나 충돌하는 답변의 확인 목록
- 현재 화면 기준의 `카테고리별 / 질문별` 왼쪽 탐색 목록
- 한 문항 집중 화면과 `목록 / 이전 / 완료하고 다음` 고정 행동
- 질문별 누적 연습 횟수와 진행 중인 세션 이어하기

## 근거 상태

- `확인됨`: 코드·테스트·워크플로에서 직접 확인
- `문서 근거`: 이력서·Wiki·README·스크린샷에서 확인
- `지원자 확인 필요`: 코드나 원본 측정 결과가 부족함
- `일반론`: 실제 구현 경험이 아니라 개념·대안 설명

## 개인정보와 저장

- 연락처와 이력서 원본 경로는 화면 데이터에 포함하지 않습니다.
- 질문별 연습 횟수는 현재 브라우저의 `interview-prep.practice-counts.v1` 키에 저장합니다.
- 진행 중인 루틴, 현재 질문, 완료한 질문은 `interview-prep.session.v1` 키에 저장합니다.
- 같은 질문은 어느 루틴에서 연습해도 질문 ID 기준으로 같은 횟수를 공유합니다.
- 왼쪽 목록의 `모든 횟수 초기화`로 저장된 횟수를 삭제할 수 있습니다.
- 메모·답변 원문·타이머·목표 횟수는 저장하지 않습니다.
- 연습 횟수는 다른 브라우저나 기기와 동기화되지 않습니다.
- 외부 분석 도구, CDN, 원격 API를 사용하지 않습니다.
- 연락처·이력서 원본·로컬 파일 경로는 공개 배포 파일에 포함하지 않습니다.

## 자산 구조

- `assets/data/`: 질문 카탈로그
- `assets/data/guide_feedback.js`: 면접 준비 가이드 검토 피드백과 가이드 반영 답변
- `assets/routines.js`: 강조점·난이도·압축 루틴 정의
- `assets/dashboard.js`: 저장·세션·URL·렌더링·상호작용 진입점
- `assets/dashboard.css`: 공개 CSS 진입점
- `assets/styles/dashboard/`: 기존 기반 스타일과 Focus 덮어쓰기 스타일

`dashboard.css`의 import 순서와 데이터 스크립트의 로드 순서는 기존 화면·세션 동작을 유지하는 계약입니다.
